# Elegant Counter App

A minimalist and elegant counter application built with SwiftUI. This app features a beautiful design with a light lavender background and deep red accents, inspired by vintage fashion aesthetics.

## Features

- Clean and modern UI design
- Increment and decrement functionality
- Elegant typography and color scheme
- Smooth animations and transitions
- Object-oriented architecture
- Dark mode support

## Technical Details

### Architecture
- Built with SwiftUI
- MVVM design pattern
- Object-oriented programming principles

### Components
- CounterModel: Manages the counter state
- CounterView: Main view component
- CounterButton: Reusable button component
- CounterDisplay: Number display component

### Color Scheme
- Background: Light lavender (RGB: 0.95, 0.93, 1.0)
- Accent: Deep red (RGB: 0.8, 0.2, 0.2)
- Text: System fonts with light weight

## Requirements

- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+

## Installation

1. Clone the repository
2. Open NoteApp.xcodeproj in Xcode
3. Build and run the project
